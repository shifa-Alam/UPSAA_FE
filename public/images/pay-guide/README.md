# Payment guide screenshots

The "কীভাবে টাকা পাঠাবেন" page (`/help/pay`) shows one screenshot per step of the
bKash app's **Send Money**. Put the files here with exactly these names (JPG, portrait,
about 720 px wide is plenty):

| File | Screen |
|---|---|
| `bkash-1-send-money.jpg` | bKash app home, with the **Send Money** button |
| `bkash-2-number.jpg` | Entering the receiver number (the association's number) |
| `bkash-3-amount.jpg` | Entering the amount |
| `bkash-4-reference.jpg` | The reference field (member code) |
| `bkash-5-pin.jpg` | The PIN screen / tap-and-hold to confirm |
| `bkash-6-sms.jpg` | The confirmation SMS with the **TrxID** |
| `bkash-7-submit.jpg` | Our Payments page with the TrxID filled in |

Before adding a screenshot, **cover or blur** anything personal: balance, your own
number, names, and of course never a PIN. A step whose file is missing simply shows
its text without a picture.
